# Use your React skills to complete this Harry Potter themed application

You will need to use your knowledge in the following areas in order to fix this React application:

- React components
- React props
- Redux

## Brief

This application is currently incomplete, which is leading to failing tests. Your job is to edit the current code to get all the tests to pass. There are 20 failing tests in total. You **DO NOT** have to edit any test files, only the code itself.

Watch this [**video recording**](https://www.loom.com/share/77c91c8b66434ebc821867abdab4cc89) to see the expected functionality of the application.

Please note there should be four working pages:
- A **homepage** (`/` route)
- A **Points page** (`/points` route) - allows you to add points to the house of your choice. The background of the widget will change colour depending on the winning house
- A **Letter page** (`/letter` route) - allows you to enter your name which in turn will generate your own letter to Hogwarts
- A **Sorting Hat page** (`/sortingHat` route) - allows you to be sorted into a random Hogwarts house on the click of a button. The background of the page will change colour depending on the selected house

#### Steps to run the application

- Run `npm install` to install dependencies.
- Run `npm run dev` to run the application.
- Run `npm run test` to run the tests.
